# 우리 반 데이터 실험실

중학교 1학년 「정보」 데이터 영역 수업용 실습 웹앱. 의존성 없는 단일 HTML 파일이라
`index.html`을 브라우저로 열기만 하면 동작한다.

## 활동 흐름 (4단계)

| 단계 | 내용 |
|---|---|
| 01 수집 | 조사 질문 선택 → 전수/표본조사 선택 → 개인정보 비식별 처리 → 원자료 29건 불러오기 |
| 02 정제 | 결측치 4 · 이상치 3 · 표기 불일치 2 · 중복 1, 총 10건을 선택지로 처리 (선택마다 피드백) |
| 03 시각화 | 변수 조합에 따라 막대·원·히스토그램·꺾은선·산점도의 적절성(◎/△/✕) 판정과 이유 제시 |
| 04 해석 | 평균·중앙값·최빈값·범위 자동 계산, 그래프 읽기 4문항, 결론 쓰기, 활동 보고서 생성 |

## 데이터

- `RAW_SURVEY` — 1학년 3반 가상 설문 29행 × 8필드 (일부러 오염된 값 포함)
- `RAW_LATE` — 학급 일지, 3~9월 월별 지각 학생 수 (6월 결측)

실제 학생 정보가 아닌 가상 데이터다.

## 참고

- 진행 상황은 브라우저 `localStorage`에만 저장된다(기기 간 공유되지 않음).
- 라이트/다크 테마, 모바일(~390px) 대응.
- 교사용 메모(성취기준·차시 운영·평가 포인트·오개념)는 페이지 하단 접힘 영역에 있다.
