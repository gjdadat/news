# news — 아침 뉴스·논문 브리핑 데스크톱 앱

매일 아침 PC를 켜면 관심 주제의 뉴스와 논문을 자동으로 모아 중요도 순 10개를 보여주는 개인용 데스크톱 앱 (Windows / macOS).

- 관심 키워드·카테고리 설정
- 아침 8시 이후 최초 실행 시 1회 자동 조사
- 제목 리스트 → [원본 가기] / [요약정리] / [더보기]
- API 키는 사용자가 직접 등록, 여러 개 저장 후 순서대로 폴백
- 노션 아카이빙(선택 — 연결한 사용자에게만 표시), GitHub Releases 기반 자동 업데이트
- 데이터베이스 없이 JSON 파일만 사용 — 설치 파일 하나로 끝

현재 **설계 단계**입니다. 설계 내용은 [docs/DESIGN.md](docs/DESIGN.md)를 참고하세요.
